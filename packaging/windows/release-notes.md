Windows port of Valkyria Revolution PS4RT, with the Ravn launcher. Unofficial, not affiliated with SEGA. The game is not included.

windows-1.2 plus:

- With [Crowbar](https://github.com/DiamondDogz/crowbar), the Guide button pauses the game (crowbar-sdk 1.2): picture, sound and timers stop while its menu is open, and the controller goes back to the game once released. During a movie, Crowbar says the game cannot pause yet.
- The Windows build on GitHub works again (GitHub's own MSYS2 no longer mixes with the build's).

Avec [Crowbar](https://github.com/DiamondDogz/crowbar), le bouton Guide met le jeu en pause (image, son et minuteries arrêtés tant que son menu est ouvert ; pendant une cinématique, Crowbar indique que le jeu ne peut pas encore se mettre en pause).

You need your own extracted copy of the base game, CUSA06810, with no update. See INSTALL.md inside the archive.
